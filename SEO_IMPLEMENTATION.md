# SEO implementation

The frontend now includes production-grade Next.js App Router SEO foundations:

- Canonical site URL from `NEXT_PUBLIC_SITE_URL` with a safe production default.
- Global metadata, title template, descriptions, Open Graph and Twitter cards.
- Dynamic social preview image generated by Next.js.
- `robots.txt`, `sitemap.xml` and web app manifest generated through Next.js metadata routes.
- Public page metadata for Home, About, Help, Tariff Library and the first calculator step.
- `noindex` metadata for account, admin, dashboard alias, saved/history pages and private calculation steps/results.
- WebSite + WebApplication JSON-LD on the home page.
- FAQPage JSON-LD on Help using questions already represented in the page content.
- `en-AU` document language and Australian-focused search phrasing.
- Root `/` is now the canonical home page. `/dashboard` redirects to `/` to prevent duplicate content.
- Internal Home links now point to `/`.

## Production environment

Set:

```env
NEXT_PUBLIC_SITE_URL=https://smartbatterycalculator.vercel.app
NEXT_PUBLIC_API_BASE_URL=https://<your-render-backend>.onrender.com
```

## Public URLs in sitemap

- `/`
- `/calculator/load-solar`
- `/tariff-library`
- `/help`
- `/about`

Authentication, admin, result-history, saved-scenario and intermediate/private calculator routes are intentionally excluded from indexing.

## After deployment

Verify these URLs:

- `/robots.txt`
- `/sitemap.xml`
- `/manifest.webmanifest`
- `/opengraph-image`

Then add the production site to Google Search Console and submit `/sitemap.xml`.

## Verification performed

- All project `.ts` / `.tsx` files passed a TypeScript syntax/transpile check.
- SEO route files and public/private metadata layouts were checked for presence.
- macOS archive metadata, temporary `.next`, partial `node_modules`, and TypeScript build cache files were excluded from the deliverable.
- Full `next build` was not run in the packaging environment because installing the dependency tree timed out; run `npm ci && npm run typecheck && npm run build` before deployment.
